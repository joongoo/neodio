# 문서 제목

| 항목 | 내용 |
| --- | --- |
| 분류 | 제품 설계 / 데이터 설계 / 기능 명세 / 운영 가이드 / 조사 기록 |
| 용도 | 이 문서를 언제 열어야 하는지 한 문장으로 설명 |
| 상태 | 구현됨 / 기획 / 보류 / 점검 기록 등, 확인 가능한 범위만 표시 |
| 확인 기준 | 현재 구현이면 코드·운영 설정, 조사면 출처·조사 시점 |

## 요약

결정 또는 현재 동작을 2~4문장으로 설명합니다. 과거 기획과 현재 구현이 다르면 여기서 먼저 구분합니다.

## 상세

기능 흐름, 데이터 계약, 운영 명령 등 이 문서의 핵심 내용을 적습니다. 필요한 하위 제목은 `##`부터 사용합니다.

## 관련 자료

- 코드나 선행 문서는 상대 경로 링크로 연결합니다.
