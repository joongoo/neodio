# 06. IP_LICENSE_REVIEW — geo-visibility-lab

> 법률 자문이 아니다. 법률 판단이 필요한 항목은 **승인 보류**.

## 1. 라이선스

- 코드: **Apache-2.0**. 허용 범위가 넓고 특허 허여 조항이 있다(일반론). 코드를 재배포·파생할 경우 라이선스 사본 포함, 변경 사실 표시, NOTICE 유지 의무가 있고, 특허 소송 제기 시 허여가 종료되는 조항이 있다.
- 상표: 로고와 회사명(恒利原)은 코드 라이선스에 포함되지 않는다(`TRADEMARKS.md`). 우리는 사용하지 않는다.
- 서드파티: Tabler Icons(MIT) 일부 아이콘 — Neodio는 사용하지 않음.
- 의존성: 서드파티 Python 패키지 없다고 README가 주장하나 `pyproject.toml`을 정독하지 않아 **미검증**.

## 2. 프로젝트 정책과의 관계

Apache-2.0이라 코드 재사용이 라이선스상 가능하지만, 이번 프로젝트 정책은 "코드 비복제, 독립 재설계"다. 따라서 **코드 이식은 법적 문제가 아니라 정책상 금지**한다. 또 언어(Python)·구조(파일 저장)가 Neodio와 달라 이식 가치도 없다.

## 3. 무엇이 보호되는가 (일반론)

| 대상 | 판단 |
|---|---|
| 소스 코드·주석·테스트 케이스 문구 | 보호됨 → 복제 금지 |
| **증거 제한 질의의 시스템 프롬프트 원문** | 표현으로 간주될 수 있어 복제 금지. 05에는 이식하지 않았고, 이 프롬프트를 쓰는 설계 자체를 채택하지 않음 |
| **부정 맥락 단서 목록, 점수 상수(순위 감점·고정 40점 등)** | 선택·배열이 표현일 수 있음 → 05에서 사용하지 않고 "보정 실험으로 결정"으로 대체 |
| 아이디어(비교 지문, 실패≠0, 신원 증거층, 문자 체계별 경계) | 일반 개념. 보호 대상 아님. 단 법적 판단은 변호사 |
| 질문 세트 스키마(`track` 두 값 등) | 05는 사용하지 않음 |

## 5. Clean-Room 수행의 한계 (정직한 기록)

- 같은 세션·같은 에이전트가 원본 읽기와 설계를 모두 수행했다. 엄격한 Clean-Room이 아니다.
- 완화책: 05에는 원본의 식별자·단서 목록·상수·프롬프트 문구를 쓰지 않았고, 일반 원리(문자 체계별 경계, 정규화, 해시 기반 비교 키, 증거 등급)만 사용했다.
- 유사성 점검: D7(문자 체계별 라틴 경계)과 D9(비교 키 해시)는 원본의 **개념**을 공유한다. 이는 일반적 공학 기법이라 위험이 낮지만, 구현 시 원본 열람을 금지하고 구조 유사성 점검을 수행한다.
