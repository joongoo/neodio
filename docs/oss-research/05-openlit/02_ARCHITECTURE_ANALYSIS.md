# 02. ARCHITECTURE_ANALYSIS — openlit @ 5edb545

## 1. 구조

```
sdk/{python,typescript,go}  자동 계측 SDK: 제공자별 계측기 + OTel 속성 규약(semcov) + 비용 계산 + 가드 + 오프라인 평가 클라이언트
src/client      Next.js UI + API 라우트 (평가 실행, 규칙 엔진, 알림, 거버넌스, 비용 요약 …)
src/otlp-receiver, src/engine, src/opamp-server   Go 서비스: 수집, 엔진, 에이전트 원격 설정(OpAMP)
src/client/prisma           설정/메타 (조직·프로젝트·DB 설정 …)
ClickHouse                  트레이스·메트릭·로그 저장(쿼리는 dataCollector 래퍼 경유)
openlit-controller          eBPF 발견 + OBI/SDK 주입 에이전트(리눅스·K8s)
opentelemetry-gpu-collector GPU 지표 수집
cli, plugins                코딩 에이전트용 CLI·플러그인
assets/pricing.json         모델 단가 JSON(임베딩, 이미지, 채팅 …)
```

## 2. 데이터 흐름

1. 앱이 SDK를 초기화 → 지원 라이브러리 호출이 **스팬/메트릭/이벤트**로 OTLP 전송
2. 수신기 → ClickHouse 저장
3. UI/백그라운드가 트레이스를 조회, **규칙 엔진**이 트레이스 속성(서비스, 스팬 이름, 모델, 도구 이름, 환경 …)으로 어떤 평가 컨텍스트를 적용할지 결정
4. **자동 평가**: 스팬 id 해시로 결정적 샘플링 → 서버측 판정 LLM 호출 → 결과 저장 → 임계값 비교로 판정/알림
5. 가드레일은 **앱 프로세스 내부(SDK)** 에서 호출 전/후에 동기 실행

## 3. 격리·계층

- 조직 → 프로젝트 → DB 설정 계층. DB 설정 읽기/쓰기/선택/핑은 현재 프로젝트 범위로 제한(AGENTS.md 명시). 오프라인 평가는 API 키 기반.
- 평가 기본 프롬프트 등은 DB 테이블에서 **캐시** 로드. 실패 시 캐시하지 않고(재시도 가능), 0행 결과도 캐시하지 않는 처리가 있다(이유 주석).

## 4. 가드 파이프라인 (SDK)

- 단계: 호출 **전(preflight)** / 호출 **후(postflight)**.
- 가드마다 지원 단계 선언, 결과 행동은 {허용, 경고, 가림(redact), 차단} 4단계, 파이프라인은 **가장 제한적인 행동**을 최종으로 채택.
- 규칙: 오류 시 기본 통과(fail-open, 옵션), 차단 시 이후 가드 중단(short-circuit), 가림은 누적 적용, 모든 가드 평가에 대해 OTel 지표·이벤트 방출.
- 가드 종류: 프롬프트 인젝션(가중치 있는 패턴 목록), PII, 모더레이션, 민감 주제, 주제 제한, 사용자 정의.

## 5. 평가 구조

- 판정 프롬프트는 평가 유형별 **컨텍스트 블록**(정답으로 취급)을 받아 유형마다 하나의 결과를 반환: {점수(0~1, 높을수록 문제 심각), 유형명, 분류 하위유형, 설명, 판정(임계값 초과 여부)}.
- 컨텍스트는 규칙 엔진이 선택. 온라인 자동 평가 샘플링 비율 기본 100%.
- 판정 호출은 제공자 SDK 매핑(OpenAI, Anthropic, Google, Mistral, Cohere, Groq 등).

## 6. 비용

- 단가는 JSON 자산을 SDK가 초기화 때 읽음(URL 또는 파일로 교체 가능). 임베딩, 이미지, 채팅 등 범주별 모델명 → 단가. 모델명 키는 제공자 접두 변형 포함(예: azure_ 접두).

## 7. 품질·운영

- 테스트 파일 약 618개, 모듈별 AGENTS.md로 규칙 명시(예: CE에 엔터프라이즈 코드 금지).
- 운영 복잡도: 다중 언어 서비스, eBPF, ClickHouse — 무겁다.

## 8. 미확인

비용 요약 로직과 가격 JSON 전체 구조, 알림 평가 실행, 거버넌스 정책 팩 세부, 컨트롤러 구현, 인증(Microsoft/Okta 로그인) 세부, SDK 계측기 내부는 **정독하지 않았다**.
