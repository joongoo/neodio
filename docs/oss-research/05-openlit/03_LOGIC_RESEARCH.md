# 03. LOGIC_RESEARCH — openlit @ 5edb545

> 정독 범위: 가드 파이프라인·기반 클래스, 프롬프트 인젝션 가드 개요, 평가 샘플링/임계값/실행 프롬프트 구조, 규칙 엔진 컨텍스트 매핑, 평가 유형 기본값 캐시, 컨트롤러 DESIGN.md, 가격 JSON 앞부분·문서. 나머지는 **미검증**. 코드·프롬프트 원문은 싣지 않는다.

## L1. 가드 파이프라인

- 목적: LLM 호출 전후에 텍스트를 검사해 통과/경고/가림/차단을 결정.
- 합성 규칙: 가장 제한적인 행동 우선, 차단 시 즉시 중단, 가림 결과를 다음 가드가 이어받음, 가드 오류는 설정에 따라 통과 또는 예외.
- 강점: 단계(전/후) 분리, 행동의 순서 척도, 모든 평가의 텔레메트리, 가드별 지연 측정.
- 한계: ① **fail-open 기본** — 가드가 죽으면 보호가 사라짐 ② 프롬프트 인젝션 가드가 가중치 있는 **정규식 패턴 목록** 기반 → 우회 쉬움, 다국어 취약(패턴이 영어 중심으로 보임, 미검증) ③ 가드가 앱 프로세스 안에서 동기 실행 → 지연 예산 필요(타임아웃 오류 클래스 존재).

## L2. 평가 판정 방식 ("컨텍스트가 정답")

- 판정 지침의 핵심: 제공된 컨텍스트는 **현실 지식과 모순돼도 정답으로 취급**하고, 응답이 컨텍스트와 어긋나면 문제로 본다(지침에 명시).
- 한 번의 호출로 여러 평가 유형을 동시에 판정(유형마다 정확히 한 개의 결과).
- 출력: 점수(높을수록 심각), 하위유형(자유 서술형 snake_case), 설명(근거 인용 요구), 판정(임계값 초과 시 "yes").
- 한계: ① 점수 방향이 "높을수록 문제"라 일반 품질 점수와 반대 → 해석 혼선 ② 다중 유형 동시 판정은 유형 간 간섭 가능 ③ 설명은 자유 서술이라 **원문 구간 검증 없음** ④ 판정 신뢰도(정밀도/재현율) 측정 장치 확인 안 됨 ⑤ 응답 텍스트를 프롬프트에 직접 삽입 — **판정 모델에 대한 프롬프트 인젝션** 방어가 이 경로에서 확인되지 않음(별도 가드 적용 여부는 미검증).

## L3. 결정적 샘플링

- 스팬 id의 SHA-256 앞 32비트를 [0,1]로 정규화해 비율과 비교. 비율 정규화 함수가 NaN/범위 밖/빈 값을 처리.
- (Langfuse의 유사 기법과 개념 동일 — 04-langfuse L2 참고.)

## L4. 규칙 엔진 → 컨텍스트 선택

- 트레이스의 일부 속성(서비스, 스팬 종류, 상태, 환경, `gen_ai.system`, 요청 모델, 도구 이름 …)을 규칙 필드로 매핑해 조건에 맞는 컨텍스트/평가를 선택.
- 가치: "어떤 응답에 어떤 정답 컨텍스트를 적용할지"를 선언적으로 관리.
- 한계: 필드 목록이 코드에 하드코딩, 값 추출 방식이 속성 경로 의존.

## L5. OTel GenAI 속성 사용

- `gen_ai.system`, `gen_ai.request.model`, `gen_ai.tool.name` 등 **공개 표준 속성명**을 사용해 다른 관측 도구와 호환. 코드에서 확인.
- 의미: 제공자·모델·도구 같은 필드의 명칭을 표준에 맞추면 데이터 이동성이 높다. (표준 자체는 아직 변경 가능한 개발 단계 사양이라 버전 의존성 주의 — 일반 지식, 이 저장소에서는 미검증.)

## L6. 비용 계산

- 모델명 키 → 토큰당 단가 조회. 사용자 정의 JSON으로 교체 가능. 이력(유효일)·조건 티어 개념은 확인한 범위에서 **없음**.
- 한계: 단가가 시점과 무관하게 최신값 하나라 과거 비용 재현 불가, 모델명 변형(접두)을 키에 중복 등록.

## L7. 컨트롤러 설계 원칙 (참고)

- eBPF로 LLM 엔드포인트 접속 프로세스 발견, IP+포트 키로 자체 호스팅 프록시도 식별, 서비스 이름의 **단일 권위자**(발견 시점에 이름 확정)와 정체성/표시명 분리 원칙. Neodio에는 해당 없음.

## L8. 품질 신호

- 테스트 성격 파일 약 618개. 규칙 문서(AGENTS.md)가 매우 구체적(경계 규칙, 문구 상수화 등).
- 약점: 가드 기본 fail-open, 정규식 기반 탐지, 판정 신뢰도 측정 부재, 다중 서비스 복잡도.
