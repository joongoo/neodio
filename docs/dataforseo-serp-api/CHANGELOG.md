# DataForSEO 수집 기능 업데이트

> 적용 예정일: 2026-11-18

프롬프트 라이브러리에서 Google AIO, Google AI Mode, Naver AIO 검색 결과를 SERP API로 수집할 수 있습니다.

## 달라진 점

- 수집을 시작하기 전에 예상 요청 수와 비용을 확인할 수 있습니다.
- 수집 중인 항목은 프롬프트 라이브러리와 수집 로그에서 확인할 수 있습니다.
- 페이지를 이동했다가 돌아와도 진행 중인 수집 내역이 다시 표시됩니다.
- 아직 API에 제출되지 않은 작업은 `수집 대기`로 표시되며, 직접 제출하거나 삭제할 수 있습니다.
- 이미 같은 프롬프트를 수집 중이라면 해당 작업의 시작 시각과 검색 엔진을 안내합니다. 그래도 다시 수집할 때만 확인 후 중복 수집을 진행합니다.
- 여러 프롬프트를 한 번에 선택해 대량으로 수집할 수 있습니다.

## 알아두세요

- API에 제출된 수집은 페이지를 떠나도 계속 진행됩니다. 다만 현재는 별도 서버 worker가 없으므로, 페이지를 떠난 동안 완료된 결과는 프롬프트 라이브러리나 수집 로그 페이지에 다시 진입했을 때 반영됩니다. 따라서 수집 중에는 페이지를 이탈하지 않는 것을 권장드립니다.
- 대량 수집은 모든 작업이 API에 제출(수집 시작)될 때까지 해당 페이지를 유지하는 것이 안전합니다.
- SERP API 수집은 실제 API 비용이 발생합니다.
  - Google AIO: 건당 $0.0024
  - Google AI Mode: 건당 $0.0012
  - 네이버 AIO: 건당 $0.0006
