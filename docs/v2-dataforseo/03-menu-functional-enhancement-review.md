## 핵심 방향

DataForSEO 전환의 제품 가치는 수집기 교체보다 **시장 수요 → 검색·AI 노출 → 브랜드 언급·인용 → 개선 과제 → 재측정**을 현재 메뉴 안에서 연결하는 데 있다.

Google AIO·AI Mode 데이터로 먼저 만들 수 있는 기능을 우선하고, Labs·Keywords·YouTube·Backlinks·AI Optimization 등은 별도 검증 후 붙인다. Google Organic 결과와 순위는 분석 대상에서 제외한다.

## PM 확정 고도화 5개

1. **AI 가시성 비교**: AIO와 AI Mode에서 자사와 경쟁사의 언급·인용을 독립 지표로 비교한다.
2. **프롬프트–콘텐츠 정합성 검증**: 캠페인 목적, 프롬프트, 자사 콘텐츠가 같은 사용자 과업을 다루는지 검증한다.
3. **경쟁 인용 분석**: 자사 대신 인용된 경쟁 URL과 반복 인용 도메인을 보여준다.
4. **데이터 기반 개선 과제**: 실제 AI 답변, 경쟁 URL, 프롬프트, 대상 자사 URL과 정합성을 한 과제로 연결하고 GSC는 우선순위 보조 근거로 사용한다.
5. **개선 전후 성과 검증**: 작업 전후를 동일 질의·지역·기기 조건으로 재수집해 관측 변화를 판정한다.

| 5. 개선 전후 성과 검증 | **기반 일부 구현** — 사이트 크롤 최초/최신 비교와 주간 언급·인용 추세가 있음 | 개선 작업과 기준 측정을 연결하고 동일 AIO/AI Mode 조건으로 전후 변화를 자동 판정 |

## Neodio 차별점 후보

- AI 답변과 인용 결과를 GSC 실측과 연결하되 GSC는 기회 우선순위의 보조 근거로 사용한다.
- 단순 언급률 대신 `언급 → 인용 → 자사 URL 인용`의 전환 구조를 보여준다.
- 일반 체크리스트가 아니라 실제 경쟁 인용 근거로 개선 과제를 만든다.
- 개선 작업을 기록하고 같은 조건으로 재측정해 관측된 성과 변화를 설명한다.
- Provider 지표의 출처·분모·측정 조건을 공개한다.

## 확장 API 구분

- **AIO·AI Mode로 가능**: 표면별 격차, 언급·인용, 경쟁 URL, GSC 보조 우선순위, 전후 재측정
- **Labs/Keywords 필요**: 검색량, 난이도, 검색 의도, 관련 키워드, Google Trends
- **YouTube SERP 필요**: YouTube 검색 순위, 영상 정보, 자막, 댓글
- **Backlinks 필요**: 인용 URL의 링크 권위, referring domain, 신규·소실 링크
- **Content Analysis/AI Optimization 필요**: 일반 웹 언급·감성과 시장 단위 LLM mentions

확장 제품은 핵심 전환의 선행 조건으로 두지 않고 한국어·대한민국 지원 품질과 실제 비용을 PoC로 확인한 뒤 추가한다.

AI 인용은 외부 요인의 영향을 받으므로 개선 효과를 보장하지 않는다. 화면과 리포트에는 관측된 변화, 개선 가설, 표본과 측정 조건을 함께 제공한다.
